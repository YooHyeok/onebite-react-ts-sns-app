# Vite React Typescript 프로젝트 설치 가이드

  ```bash
  npm create vite@6.5.0 onebite-react-ts-sns-app
  ```

- 뷰 프레임워크 선택 : `React`
  ```console
  > npx
  > cva onebite-react-ts-sns-app

  |

  |    Vue
  |  > React
  |    Preact
  |    Lit

  ```
