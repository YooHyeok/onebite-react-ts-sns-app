# _**Shadcn/Ui란?**_

<details>
<summary>접기/펼치기</summary>
<br>

Bootstrap이나 Material UI처럼 현대 웹 개발에 필요한 거의 대부분의 필수적인 UI 요소들을 제공하는 디자인 라이브러리이다.  
모던한 디자인과 편리한 사용법 등의 이유로 2024년 State Of Frontend 설문 결과에서 전통의 강자인 Material UI와 Bootstrap을 제치고 디자인 시스템 부문 1등을 차지할 만큼 세계에서 가장 맣은 사람들에게 사랑받고 있는 디자인 라이브러리이다.

Shadcn UI는 Tailwind CSS 기반으로 제작 되어 Tailwind CSS를 사용하는 환경에서 커스터마이징 하기 굉장히 편하며 호환성 문제 또한 크게 걱정하지 않아도 된다는 이점이 있다.

- [Shadcn/ui 공식 문서](https://ui.shadcn.com/)
- [Shadcn/ui 설치 가이드](https://ui.shadcn.com/docs/installation/vite#existing-vite-project)
